EcoClasifica IA

Tomas una foto, la IA te dice a qué caneca va tu residuo.

Conoce el proyecto

El problema

En los campus y en las ciudades, los residuos se tiran mezclados. Plástico, papel y vidrio aprovechables terminan junto a restos de comida y basura no aprovechable, y el material reciclable se contamina. Muchas personas no saben a qué caneca va cada objeto y clasifican por intuición.

Nuestro enfoque es concreto: ayudar a clasificar bien en la fuente, dentro de un campus universitario, en tres categorías: aprovechables, orgánicos y no aprovechables.

Nuestra solución: cómo funciona la IA

1. Foto
Desde el celular, sin instalar nada, el usuario fotografía el residuo.
2. Petición
El navegador (cliente) envía la imagen por HTTP a un servidor remoto.
3. Clasificación
Una red neuronal convolucional en Python identifica el tipo de residuo.
4. Respuesta
El servidor devuelve la caneca correcta y un consejo breve. La imagen no se almacena.

Impacto esperado

Mejor separación
Más residuos depositados en la caneca correcta.
Menos contaminación
Menos material reciclable arruinado por mezclas.
Hábito y educación
Respuesta inmediata que enseña mientras se usa.
Escalable y de bajo costo
Solo requiere el celular que ya tienen los usuarios.

Abstract

Improper waste segregation at the source remains a major obstacle to recycling in university campuses and urban communities. Mixed disposal contaminates recyclable materials, increases the volume sent to landfills, and overloads collection services. This paper presents the conceptual design of EcoClasifica IA, a web application that uses computer vision to tell users, in real time, which bin each waste item belongs to. Following an engineering design process based on problem-based learning, we formulated the problem, identified technical, economic, legal, and ethical constraints, and evaluated three alternatives: a computer vision web app, a natural-language chatbot, and IoT-enabled smart bins. A weighted decision matrix favored the web app because of its low deployment cost, minimal hardware requirements, and strong potential to build lasting habits. The proposed architecture follows a client-server model: the user's browser captures an image and sends an HTTP request to a remote server, where a convolutional neural network classifies the item and returns the result as an HTML and JavaScript response. Images are processed without being stored, in line with data protection principles. Although no functional model was implemented at this stage, the design defines the system architecture, data flow, and evaluation metrics, such as classification accuracy and user adoption. We expect EcoClasifica IA to increase correct segregation rates, reduce contamination of recyclable streams, and offer a scalable, low-cost educational tool that can later be extended to other institutions.

Keywords: waste management, computer vision, artificial intelligence, web application, client-server architecture, recycling.
